# Python Data Automation & Spreadsheet Cleaner

A collection of lightweight, high-performance Python scripts designed to eliminate manual data entry errors, clean messy CSV/Excel datasets, and automate repetitive file workflows.

---

## 🚀 Features
* **Automated Data Cleaning:** Instantly strips leading/trailing whitespaces, standardizes column headers, and removes exact duplicate rows.
* **Format Support:** Seamlessly ingests and exports both `.csv` and `.xlsx` files.
* **Bulk Processing Ready:** Easily adaptable script structures to handle multi-file operations and large datasets.

---

## 🛠️ Tech Stack
* **Language:** Python 3
* **Core Libraries:** `pandas`, `openpyxl`, `glob`
